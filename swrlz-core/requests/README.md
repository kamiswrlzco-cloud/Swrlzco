# SWRLZ Requests

Structured request files live here.

- `client/` — CLIENT-specific changes/build requests
- `server/` — SERVER-specific changes/build requests
- `brain/` — brain/knowledge-pack requests
- `inbox/` — generic or not-yet-routed requests

Executable GitHub Actions workflow YAML does **not** belong here; put it in
repository-root `/.github/workflows/`.
