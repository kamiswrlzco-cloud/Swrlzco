# AGENTS

Guidance for automated agents working on the SWRLZ repository.

- Source of truth: code > releases > WordMesh manual > other docs.
- Implementation status rules: use `IMPLEMENTED`, `PARTIAL`, `PLANNED`, `EXPERIMENTAL`, `DEPRECATED`, `UNKNOWN`.

Agent guidance:

- Always prefer direct code evidence over documentation when labeling status.
- When updating docs, include exact file paths and code links for evidence.
- Build commands (client): see `CLIENT_CFv2.0.69_SWRLZ/android/README_LATEST_2.7.1.md` or the package `frontend/package.json` for web UI tasks.
