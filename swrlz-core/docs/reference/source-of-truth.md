# Source of Truth

Authority for implementation evidence in the new official repository:

1. Current source package and matching SHA-256 under `swrlz-core/sources/`.
2. Current `kamiswrlzco-cloud/Swrlzco` repository HEAD and direct code evidence.
3. Build/workflow logs, provenance, artifacts, and verified release evidence.
4. Maintained documentation under `swrlz-core/docs/`.
5. WordMesh architecture/specification documents.
6. Historical Documentation Rebuild v2, prior repository snapshots, and `.reference` evidence.

Historical source is evidence of lineage, not automatic authority for current behavior.

Compilation, device behavior, integration behavior, and source presence are separate evidence
classes and must not be conflated.
